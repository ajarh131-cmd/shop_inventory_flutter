# Shop Inventory — Flutter

Готовая основа мобильного приложения для iOS + Android.

Первый вход: **admin / admin123**.

## Запуск
1. Установите Flutter.
2. В этой папке: `flutter pub get`
3. Затем один раз: `flutter create .`
4. Запуск: `flutter run`

Для iPhone добавьте в `ios/Runner/Info.plist`:
```xml
<key>NSCameraUsageDescription</key>
<string>Камера используется для сканирования штрихкодов товаров.</string>
```

База старого проекта уже включена в `assets/shop.db`; приложение копирует ее в локальное хранилище телефона и выполняет миграции.

В текущей версии есть вход, роли, товары, камера-сканер, корзина, продажи, возврат, брак, история, статистика, продавцы и резервная копия. Для нескольких телефонов следующей стадией будет серверная синхронизация.
